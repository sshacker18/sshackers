# PORTAL — Short Film VFX Starter Project

A starter production pack for a short film in which a person sitting in a room opens a glowing sci-fi portal.

## Project files
- [Shot plan](SHOT_PLAN.md)
- [Asset links](ASSET_LINKS.md)
- [Compositing workflow](COMPOSITING_WORKFLOW.md)

## Recommended workflow
1. Film a locked-off room shot and a clean plate.
2. Download portal/energy overlays, particles and sound effects from the links in ASSET_LINKS.md.
3. Composite the portal behind the actor in DaVinci Resolve/Fusion, After Effects, or Blender.
4. Add blue light spill to the actor and room so the effect feels integrated.
5. Export a short 1080p test before rendering the final shot.

This repository folder contains production documentation and official library links. Third-party assets are not bundled here; download them from their official pages and confirm the current licence terms before using them in a released film.
